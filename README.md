One line, under 200 characters, about crypto and trading life. A judge model reads them two at a time and picks the funniest.

> I drew so many lines on the chart it filed for harassment.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/laugh-track-out python3 main.py && cat /tmp/laugh-track-out/entry.txt
```
